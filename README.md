# Music generation with our own Transformer models

This is our class music-generation project. It started from MIT 6.S191 Lab 1, a character-level LSTM, and replaced it with small GPT-style Transformers. We trained them from scratch, all with the same `model.py` and `train.py`.

## Final piece: `journey2.py` (Journey / Mark Eliyahu-inspired, F minor, 81 BPM)
| Part | Who made it |
|---|---|
| Theme melody | `ckpt/tr.pt`: melody+chord model trained on Hooktheory (18k Western pop sections), fine-tuned on 107 Turkish makam pieces (`prep_ht.py`, `prep_tr.py`). Generated by `refgen.py --profile journey`. |
| Climax melody | Same model. It continues the theme over VI-VII-i-i, steered towards a higher register and longer notes (`journey2.py`). |
| Ending phrase | Same model. Guided decoding slows the phrase down so it settles on the tonic (`ending.py`). |
| Chord skeleton, arrangement, mix | Us: we chose the chords, and code does the piano ostinato, daf pattern, the instruments and the mix automation. |
| Sounds | Surge XT factory patches (`surge.py` loads .fxp patches through pedalboard) and MuseScore's MS Basic expressive orchestra. Karplus-Strong saz. |

Originality check: no 6-, 8- or 12-note melody fragment of the piece appears in the training data.

# Folk tune generator (char-level GPT on ABC notation)

Extends MIT 6.S191 Lab 1 (char LSTM on ~800 Irish tunes) to a 25.7M-param Transformer trained on ~56k tunes,
fine-tuned on chord-annotated tunes so the model writes its own accompaniment chords.

| Step | Command | Notes |
|---|---|---|
| Data | `python prep.py` | TheSession dump (55k tunes) + Nottingham DB (1k, chorded) -> `data/session.txt`, `data/chords.txt` |
| Pretrain | `.venv/Scripts/python train.py --data data/session.txt --out ckpt/base.pt --iters 15000` | ~60 min on RTX 5060, best val loss 0.758 nats/char |
| Fine-tune | `.venv/Scripts/python train.py --data data/chords.txt --out ckpt/ft.pt --init ckpt/base.pt --iters 600 --lr 1e-4` | ~3 min, model learns to write `"Am"`-style chord symbols |
| Generate | `.venv/Scripts/python generate.py --type jig --meter 6/8 --key Dmaj --n 150` | nucleus sampling, then filters: parses, 8-80 bars, ends on tonic, <50% 24-char overlap with training data |
| Render | `.venv/Scripts/python render.py candidates/jig_Dmaj_000.abc --style folk` | melody + model chords -> fiddle/flute/guitar/bass/bodhran MIDI -> FluidSynth WAV |

Render styles: `folk`, `whistle`, `harp`, `piano`. Tempo override: `--qpm 140`. Length: `--min_sec 50`.

What the model decides: every melody note, rhythm, form (repeats/endings) and chord symbol.
What the script decides: instruments, tempo, accompaniment pattern (bass on beats, guitar strums), final held chord.

## Final eser: kendin ayarla

`ayarlar.json` dosyasını düzenle, sonra çalıştır:

```
.venv/Scripts/python compose.py ayarlar.json      ->  final/eser.wav
```

- Ezgiler `ezgiler/` klasöründe: `huzun_*` minör (Si♭), `umut_*` majör (Si). Bölümlerin `"melodi"` satırına dosya adını yaz.
- `solist`: `cello`, `keman` ya da `ikisi`. `keman_oktav: 1` kemanı bir oktav yukarı taşır (umut bölümü için).
- `tempo` (52–66 hüzünlü), `ton_kaydir` (−2 daha karanlık), `keman_ses` / `cello_ses` / `yayli_akor_ses` / `kontrbas_ses`, `yanki`, `salon_buyuklugu`, `vibrato`.
- `gecis_saniye`: giriş, çıkış ve bölüm geçişlerinin kaç saniyede yumuşakça olacağı.
- `guc_baslangic` / `guc_bitis` (0–1): bölüm içindeki crescendo ve diminuendo.
- Bütün anahtarların açıklaması dosyanın `_aciklama` kısmında.
- Hazır alternatif: `ayarlar_alternatif.json` (farklı bir hüzün teması).

Orkestra: solo keman ve solo çello, arkada keman grubu, viyola, çello grubu ve kontrbas. MuseScore 4'ün `tools/MS_Basic.sf3` ses bankasındaki "Expr." seslerini kullanıyor; ses gücü CC2 ile nota tutulurken bile pürüzsüzce değişiyor. Akor sesleri en yakın notaya giderek ilerliyor, aynı nota sürüyorsa yeniden basılmadan bağlanıyor.

## Makam model (melody source)

Second model: 11.1M-param GPT trained on SymbTr (2,175 Turkish makam pieces, 53-comma microtonal pitch), 5x transposition
augmentation, conditioned on makam / form / usul tokens. Best val loss 0.761 per token.

| Step | Command |
|---|---|
| Data | `.venv/Scripts/python prep_makam.py` (needs `data/symbtr/txt`, sparse clone of MTG/SymbTr) |
| Train | `.venv/Scripts/python train.py --data data/makam/train.txt --vocab data/makam/vocab.json --out ckpt/makam.pt --iters 8000 --size 384,6,6,512,0.2 --batch 48` (~16 min) |
| Generate | `.venv/Scripts/python gen_makam.py --makam hicaz --form sarki --usul duyek --n 100` (cuts at a phrase ending on the karar, drops loops/copies) |
| Rank + render | `.venv/Scripts/python rank_makam.py --per_group 2` -> `makam_shortlist/` |
| Re-render | `.venv/Scripts/python render_makam.py makam_shortlist/02_*.json --lead cello --qpm 66` |

Arrangement (render_makam.py): drone + santur intro -> cello sings the first phrase -> violin takes the melody with bow swells
and delayed vibrato, cello supports from below -> climax: cello doubles an octave under, frame drum enters -> ritardando into
the held karar. Microtones are kept with per-note pitch bend.

Requires: `.venv` with torch cu128 (RTX 50xx needs CUDA 12.8+), music21, mido; `tools/` holds FluidSynth 2.6.1 and GeneralUser GS soundfont.
